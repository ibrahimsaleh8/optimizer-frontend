# Optimo — Image Converter & Compressor

Optimo is a powerful and easy-to-use web application that allows users to **convert images between multiple formats** and **compress images with adjustable quality**.  
Built with **Next.js**, **React**, **Tailwind CSS**, and **Shadcn UI** — Optimo delivers a fast, responsive, and modern user experience.

## 🚀 Features

### 🔄 Image Format Conversion

Convert images between the most commonly used formats:

- PNG → JPG / WEBP / GIF / AVIF
- JPG → PNG / WEBP / GIF / AVIF
- WEBP → PNG / JPG / GIF / AVIF
- GIF → PNG / JPG / WEBP / AVIF
- AVIF → PNG / JPG / WEBP / GIF

### 📦 Image Compression

Compress images while controlling the quality level:

- Supports PNG, JPG, WEBP, AVIF
- Adjustable compression slider (10 → 100)
- Reduce file size while preserving quality

### ⚡ Fast & Optimized

- Optimized client + server processing
- Clean UI using Shadcn components
- Responsive layout with Tailwind CSS
- Built using Next.js App Router
